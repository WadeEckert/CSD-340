# CSD 340 - Web Development with HTML and CSS

Repository for Wade Eckert for CSD 340 - Web Development with HTML and CSS.

This repository contains my coursework and programming assignments completed for **CSD 340 - Web Development with HTML and CSS** at Bellevue University. Throughout this course, I learned the fundamentals of front-end web development by designing and building modern, standards-compliant websites using HTML5, CSS3, and introductory JavaScript.

Assignments gradually progressed from creating simple web pages to developing complete multi-page websites while emphasizing clean code organization, responsive design principles, accessibility, and user experience.

## Major Projects

Some of the larger projects completed during this course include:

- Multi-page website development
- Responsive navigation systems
- Image galleries
- Personal portfolio web pages
- The **bioSite** project, which involved designing and developing a complete multi-page website based on interviews with a selected individual. The project emphasized responsive layout design, consistent navigation, reusable styling, accessibility, and professional visual presentation. Note: the source code, images, etc., for this project are contained in its own bioSite repository on my account. 

These projects demonstrate the progression from basic HTML documents to fully styled, responsive websites using modern front-end development practices.
